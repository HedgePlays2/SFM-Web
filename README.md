Overview
Web‑SFM is a web‑native 3D animation and posing tool inspired by Valve’s Source Filmmaker (SFM).
It recreates the feel of SFM inside the browser using Puter.js, allowing it to run as a full desktop‑like application without requiring installation or the Source engine.
🧩 Powered by Puter.js
Web‑SFM is built on Puter.js, a framework that provides:

A virtual filesystem

A desktop‑style UI environment

App windows, menus, dialogs, and sandboxing

Persistent storage

Multi‑app interoperability

A lightweight OS‑like runtime inside the browser

This allows Web‑SFM to behave like a native desktop program, but entirely online.

🎮 What Web‑SFM Is
A Puter.js application that runs inside a virtual desktop

A WebGL/WebGPU 3D editor with SFM‑style posing

A timeline animation system similar to SFM’s graph editor

A camera viewport modeled after SFM’s shot editor

Model importing via GLTF, GLB, OBJ

Real‑time rendering using browser shaders

It’s SFM‑inspired, but fully web‑native.

🚫 What Web‑SFM Is Not
Not the official Valve SFM

Not built on the Source engine

Does not support MDL, VTF, VMT, QC, or DMX

Does not include SFM’s procedural animation tools

Does not replicate SFM’s physics or lighting system exactly

⚡ Why Puter.js?
Using Puter.js gives Web‑SFM several advantages:

Runs inside a virtual OS with windows and apps

Supports drag‑and‑drop file importing

Allows saving scenes to the Puter filesystem

Integrates with other Puter apps (image editors, file managers, etc.)

Works on any device with a browser

Perfect for ARGs, browser OS projects, and web‑based games

It feels like a real program, not just a webpage.
